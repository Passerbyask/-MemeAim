# MemeAim 3D 网页版

接手开发请先阅读 **[Web 开发交接文档](HANDOFF.md)**，包含代码地图、常见修改入口、特效约定和发布检查。

在原版 Python / pygame 游戏之外，新增一个独立的 Three.js 练枪场。原桌面版文件和运行方式保持不变。

## 本地运行

需要 Node.js 22 或更新版本。在仓库根目录执行：

```sh
cd web
npm ci
npm start
```

打开 http://localhost:8765 。关闭终端服务后停止访问。服务仅监听本机 `127.0.0.1`，只提供 `web/dist/` 中的静态文件。

不要直接双击 index.html；浏览器加载 JavaScript 模块需要 HTTP 服务。

## 控制和训练模式

- 点击「开始训练」→「进入训练」。
- 第一人称：鼠标转动视角，左键按中心准星射击；手持枪带有双手、枪口闪光、后坐动画和轻微随动。
- 自由指针：直接点击立体靶球，也支持触屏点按。
- Esc：暂停并释放鼠标。切换窗口或标签页也会暂停；暂停期间冻结计时。
- 浏览器限制鼠标锁定时，页面提供自由指针模式。

| 模式 | 行为 |
|---|---|
| Gridshot / 精准速点 | 多个静止靶球，击中后补充 |
| Tracking / 移动追踪 | 靶球持续移动并在边界反弹，点击射击 |
| Flick / 闪现甩枪 | 单个靶球限时出现，到期刷新 |

沿用原版计分：命中 +1，打空 -1 且最低为 0；打空或闪现目标消失会中断连击。目标消失不扣分。Tracking 为点击命中，并非按住持续累计伤害。枪械后坐只影响枪模，不改变中心准星的射线。

## 手柄操作

连接标准布局手柄后先按一下按键唤醒。首页按 A / × 可直接选择手柄模式并开始，也可以在「瞄准方式」中手动选择手柄。

| 按键 | 操作 |
| --- | --- |
| 右摇杆 | 瞄准；固定站位训练，不使用左摇杆移动角色 |
| RT / R2 | 按住连续射击，最多约每秒 6 枪 |
| LT / L2 | 按住降速精瞄 |
| A / × | 确认、进入训练；训练中单发 |
| B / ○ | 训练中暂停，菜单中返回首页 |
| Start / Options | 开始、暂停、继续 |
| 方向键左右 / LB、RB | 首页切换训练模式 |
| 方向键上下 / 左摇杆上下 | 选择暂停/结算菜单操作 |

手柄有独立灵敏度和摇杆死区设置。断开或切换手柄会暂停；重连不会自动开枪或继续，需松开按键后确认。手柄使用中心准星，成绩与鼠标配置分开记录。

仅自动接受浏览器识别为 `standard` 的按键布局；非标准手柄请切换 XInput 模式。网页通过 Gamepad API 读取输入，需浏览器提供该接口；浏览器可能要求先点击一次页面才能播放声音。支持时开枪轻震、命中较强震动，可独立关闭；暂停、断线、返回及关闭开关时停止。震动依赖设备和浏览器的双马达接口。支持下述体感接入；暂不提供逐键自定义映射。

## 手柄测试与体感瞄准

打开顶部「手柄测试」，可选择当前已连接的手柄：

- 左右摇杆：橙点为原始值，绿点为经过训练死区和响应曲线处理后的值；沿外圈旋转可留下范围轨迹。
- 点击「测中心漂移」，松开摇杆静置两秒；查看左右中心偏移峰值，再选择是否采用建议死区。建议范围为 5%–35%，不是硬件合格判定。
- 同时查看全部轴、按键数值、扳机深度，或发送一次短震动。非标准布局也能观察原始输入；训练仍要求标准布局。

**DualSense / DualSense Edge**：点击「连接 DualSense 陀螺仪」，在设备选择框授权。先确认实时角速度有变化，再放稳手柄点击两秒校准。开启体感瞄准，并在训练首页选择「手柄」。默认按住 LT / L2 生效，可改为始终启用，调整灵敏度、水平旋转轴及方向反转。校准值仅保留本次连接，重新连接需要重新校准；更改设置后从首页开始新一局。

网页直连需要支持 WebHID 的桌面浏览器和 HTTPS（本机 localhost 可用）；Windows 软件版也提供相同连接按钮。USB 和完整蓝牙报告均有解析，设备未输出运动数据时会显示等待。当前采用名义角速度比例加静止零偏校准，并非工厂精度校准。

**Xbox**：标准输入没有陀螺仪数据，可使用右摇杆和完整测试页。**飞智等国产手柄**：摇杆/按键可按系统返回布局测试；体感取决于具体型号、模式和驱动。如果已有驱动或工具能将真实陀螺仪数据输出为 Cemuhook DSU，可在 Windows 软件版展开「连接本机 DSU 运动服务」，填写端口（默认 26760）和槽位。服务限定本机；普通网页不能直接接收 UDP。此版本不包含飞智专有协议驱动，不能保证所有型号直连体感。

体感只在手柄训练且窗口处于前台时影响视角，可与右摇杆同时使用。数据超过 300ms 未更新时停止体感移动；校准时或校准失败时也不会移动。协议、扩展入口及验证范围见 [MOTION.md](MOTION.md)。自动检查使用协议样本和模拟设备，尚未逐款实体手柄实测。

## 设置与本地记录

- 10–180 秒时长预设、灵敏度、靶球半径/数量、追踪速度、闪现停留时间。
- 十字/圆点/圆环准星与四种颜色。
- 随机梗音效、逐项试听与开关、音量、静音，结算沿用 60 分阈值的 w.mp3 / l.mp3。
- 当前浏览器保存设置、最近 50 局和按配置区分的最佳成绩；提前结束的局不计入最佳成绩。
- Three.js 和音效均由构建复制到本地输出，无运行时 CDN 依赖。

此版为中文界面，尚未迁移英文切换、背景音乐、准星线宽/间隙设置。浏览器自适应画布取代桌面版分辨率预设。3D 尺寸使用场景单位，不直接对应原版像素。无账号、云同步或在线排行榜。

推荐支持 WebGL 2 的桌面 Chrome / Edge。鼠标锁定要求用户点击，嵌入式浏览器可能限制。清除网站数据会清除本地成绩；不同域名的成绩相互独立。

## 测试与部署

### 绿幕梗与反差特效

新增 18 段静音短视频，包括人物/表情梗、爆炸、烟火和中国金龙与火焰合成。命中和打空各有反应池，共享爆炸类片段，随机选择且同组不连续重复。每次在整个训练画面内随机位置、随机大小出现，没有底部文字；特效不拦截鼠标。快速连续射击限频，同时只显示一段。暂停、结算、返回或关闭特效时立即收起。

设置中可开关特效，并预览命中、打空和神龙。爆炸音效遵守音量和静音设置。视频由 `meme-effects.mjs` 实时抠除绿色背景，原始声音已去掉；来源和合成说明在 [effects/SOURCES.md](effects/SOURCES.md)。构建产物包含所有特效，不依赖第三方视频站点。

### 验证命令

```sh
npm test
npm run build
```

将生成的 `web/dist/` 部署到 HTTPS 静态托管即可，无需后端。构建从仓库根目录 `sounds/` 收集音效，因此 CI 应检出整个仓库后在 `web/` 内运行构建。

`core.test.mjs` 覆盖计分、连击、目标到期、计时结束、配置隔离和设置校验。浏览器手动检查建议：三种模式、鼠标锁定/释放、暂停恢复、刷新后记录、音效开关、窄屏布局。

Three.js 锁定为 0.180.0，其 MIT 许可证随构建复制到 `dist/vendor/THREE-LICENSE.txt`。音效继续使用上游素材，不另行授予素材许可。

全屏效果使用 5 段下载视频：两种烟花、两种爆炸和卡通火焰，透明抠绿叠加。命中和打空均可触发，间隔至少 3.6 秒，每段 2.6 秒，暂停、结束和关闭开关会清理。在设置中点击“全屏”预览。普通梗继续随机位置和大小，无附加标签。

全屏池同时保留 6 种程序动画（烟花、火焰、爆炸、冲击波、流星、礼花）和 5 段视频，共 11 种随机效果，共用触发间隔并避免连续重复。
