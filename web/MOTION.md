# 手柄测试与体感接口

v1.2.0。游戏和测试页共用 Gamepad API；体感单独读取，不把摇杆模拟成传感器。

| 设备 / 环境 | 摇杆、按键与死区测试 | 真实体感来源 |
| --- | --- | --- |
| DualSense / Edge，支持 WebHID 的桌面 Chrome / Edge | 系统 Gamepad API | 用户选择的 Sony HID 设备；HTTPS 或 localhost |
| DualSense / Edge，Windows 软件版 | Electron Gamepad API | 同样的 HID 报告，通过原生设备选择框授权 |
| Xbox 标准输入 | 支持标准布局；震动取决于接口 | 标准输入不提供陀螺仪数据 |
| 飞智等国产手柄 | 可观察原始布局，标准布局用于训练 | Windows 版可接已有驱动输出的 DSU；不保证任意型号/模式，不含专有驱动 |
| 不支持 WebHID 的普通浏览器 | 取决于 Gamepad API | 没有网页直连体感；网页不能直收 UDP |

## 用户流程

1. 打开「手柄测试」，连接手柄并按一下按键唤醒；选择待测试设备。
2. 松开双摇杆，点击「测中心漂移」等待两秒。橙点为原始值，绿点为训练死区与二次响应曲线后的值。建议死区加 2% 余量，限制在 5%–35%，需手动采用；外圈轨迹不是质量认证。
3. DualSense 点击直连按钮并授权；其他手柄在已有 DSU 输出服务时使用 Windows 版入口，默认端口 26760、槽位 1。所有型号均以实时角速度是否更新为准。
4. 手柄放稳后点击「静止校准」，两秒内至少 20 个样本，各轴方差不超过 2.25 (°/s)²，均值绝对值不超过 15°/s。失败或丢流后放稳重试。
5. 开启体感，在首页选择「手柄」并开始新一局。默认按 LT / L2 才应用体感，可选训练中始终启用。按握持方式选择水平 Y/Z 轴，必要时反转。重新连接必须重新校准。

## 协议实现

### DualSense WebHID

`gyro.mjs` 允许 VID `0x054c`，PID `0x0ce6` / `0x0df2`。浏览器 `inputreport.data` 不包含 report ID：USB `0x01` 至少 63 字节，三轴 int16 LE 位于偏移 15/17/19；完整蓝牙 `0x31` 至少 77 字节，偏移 16/18/20。短蓝牙基础报告不含体感，明确拒绝。读取 feature report `0x05` 以请求完整蓝牙报告；失败仍等待实际输入，不虚构数据。

使用 16.4 原始单位 / (°/s) 的名义比例；两秒校准只扣除静止零偏，**没有应用工厂增益/温漂标定**。不读写自适应扳机或复杂触觉，不修改系统驱动。

协议参考：[DualSense Explorer](https://github.com/nondebug/dualsense)、[Linux hid-playstation](https://github.com/torvalds/linux/blob/master/drivers/hid/hid-playstation.c)。

### 本机 DSU

`desktop/dsu.cjs` 使用 Cemuhook v1001 UDP 协议，固定 IPv4 `127.0.0.1`，可配置端口 1024–65535 和槽位 0–3（界面显示 1–4）。按一秒间隔发送 `0x100002` 槽位订阅；不做公网连接或自动发现。

接收 100 字节数据包，校验 magic、版本、长度、类型、槽位、连接状态和 CRC32；从偏移 68 读取运动时间戳，88/92/96 读取三轴 float32 °/s。拒绝重复/倒序时间戳、损坏包和非有限值/绝对值超过 4000 的角速度。断开再连接清空时间戳。

DSU 只是可选输入接口，用户需自行提供实际运动输出服务。没有测试或承诺某个飞智型号/官方驱动提供该输出；未知设备不会擅自套用 Sony 数据布局。参考：[Cemuhook protocol](https://github.com/v1993/cemuhook-protocol)。

### 渲染与生命周期

`GyroState` 接收样本，`delta()` 按 °/s × 秒 × π/180 × 灵敏度转换视角，单帧最多 50ms。只有启用、完成校准、最新样本不足 300ms 且满足按键条件时输出；游戏仍要求标准手柄连接、手柄模式、训练运行且前台。体感可与右摇杆叠加。暂停、断线或失焦沿用游戏暂停保护。

连接清除旧偏置与采样；只保存用户设置，不保存设备授权数据、原始运动样本或校准偏置。开启体感的成绩使用额外配置段，旧无体感成绩不变。

## Windows 边界与扩展

`preload.cjs` 在隔离上下文只暴露 `connect` / `disconnect` / `onMotion`。主进程要求请求来自受信 `memeaim://app/` 主框架；UDP 地址不能由页面更改。HID 设备选择仅允许上述 Sony ID，系统 HID 屏蔽列表保持启用。保持 Electron 沙箱、无 Node 页面权限和离线 HTTP/HTTPS 拦截。WebHID 权限处理依据 [Electron 设备文档](https://www.electronjs.org/docs/latest/tutorial/devices#webhid-api)。

新增型号应先取得可验证的报告协议与实际样本，另写解析器和测试，并限制对应 VID/PID；不要仅添加设备 ID 后误用 Sony 偏移。若支持其他运动坐标系，明确单位/方向并测试，保留手动轴与反转设置。

## 验证范围

- Web 单元测试：USB/完整蓝牙解析、短报告拒绝、稳定/移动/中断校准、过期停止、轴/反转/设置及成绩分类、中心漂移时间窗。
- 桌面测试：校验与 CRC、真实本机 UDP 收发、重复/乱序过滤、连接取消，以及离线资源边界。
- 实际打包程序 smoke：虚拟 Gamepad + HID 报告驱动真实页面和帧循环，检查轴/按键/扳机、建议死区、震动调用、连接校准、实时值、过期清空与持久化。

自动验证不能证明所有实体手柄、USB/蓝牙驱动、HID 占用或震动马达兼容。发布后需按型号实机确认；未连接设备时界面显示等待，不生成示范运动值。
