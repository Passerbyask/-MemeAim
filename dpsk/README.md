# MemeAim 3D-DeepSeek V41 v1.0.0

这是 `dpsk` 分支的独立正式版本，源于用户提供的单文件六模式项目。桌面程序为 **MemeAim 3D-DeepSeek V41**，版本号独立维护，与 main 的 Three.js 版并行。

## Windows 桌面版

Releases 中下载名称含 `DeepSeek-V41` 的 Setup.exe 或 Portable.zip。免安装包必须完整解压，再运行 `MemeAim 3D-DeepSeek V41.exe`。运行时无需网络、Python 或 Node.js；音效默认关闭。窗口按 F11 全屏。

设置和成绩保存在当前 Windows 用户的 `MemeAim 3D-DeepSeek V41` 应用数据目录，与 main 版及浏览器版分开。此版沿用输入项目的鼠标/触屏操作，不包含 main 的手柄测试和陀螺仪功能。当前安装包没有商业代码签名。

开发构建（仓库根目录，Node.js 24）：

```sh
npm --prefix desktop ci
node dpsk/tests/store.cjs
npm --prefix desktop test
npm --prefix desktop run dist
npm --prefix desktop run smoke
```

`dpsk/src/` 是可编辑源文件，`dpsk/build.mjs` 生成单文件 `dpsk/dist/index.html`。桌面打包共用 `desktop/` 外壳，`web/` 和根目录 Python 版保留用于历史参考，不进入此版本安装包。

仅推送 `dpsk-v版本号` 标签触发本分支正式 Release，例如 `dpsk-v1.0.0`；标签须匹配 `desktop/package.json` 版本。发布显式使用 `--latest=false`，不取代 main 的默认正式版入口，也不改动现有网站。原始输入的文件哈希记录在 `IMPORT.json`，仅为本分支统一显示名称和接入桌面打包作必要改动。

# MEMEAIM 3D-DeepSeek V41 · 网页瞄准训练器

一个本地运行、单文件、无需安装的 Aim Lab 风格瞄准训练器。第一人称亮灰白训练舱、六种训练模式，
成绩保存在本机浏览器；另外接入了一整套「节目效果」：梗音效、绿幕梗视频、Twemoji 表情包和全屏特效。

- **版本**：1.0.0（2026-10-18）
- **交付文件**：[`aimlab.html`](./aimlab.html)（单文件，约 4.8 MB，全部素材已内联）
- **运行方式**：直接双击 `aimlab.html`，用 Chrome / Edge 打开即可；不需要服务器、Node 或网络。
- **适配**：桌面鼠标优先，同时支持触屏；相对瞄准 / 绝对瞄准可切换。
- **真第一人称 3D 场景**：鼠标转动 yaw/pitch 视角；训练舱、透视地面、全息靶墙、立柱、顶灯和
  漂浮粉尘都按 3D 相机投影渲染，靶子也会随视角透视移动；准星固定在画面中心。
- **代码生成的 3D 枪模**：枪口朝前的第一人称步枪，由侧面轮廓沿厚度挤出成多面体，再做透视投影
  和明暗面渲染；枪口指向准星方向，带视角滞后、呼吸摆动、开火后坐和 3D 枪口焰。没有任何外部
  模型文件，也不使用建模软件。
- **亮灰白训练舱**：射击场景改成浅灰白配色和柔和顶光，不再压暗；底部 HUD 文案同步切深色，
  兼顾亮场可读性。
- **HDR / 广色域增强**：设置 → 操作里有独立的「HDR 高光」开关。只有系统/显示器声明高动态
  范围时开关才可操作；开启后右上角显示 `HDR` / `HDR · P3` 标记并启用峰值高光。不支持 HDR 的
  设备开关置灰，完全走普通渲染：不加滤镜、不改配色、不显示 HDR 标记。网页 Canvas 无法保证
  输出真正的 HDR 亮度，最终效果取决于显示器、浏览器和系统 HDR 开关。
- **Aim Lab 风格球形靶**：目标为干净的实心蓝色小球，只保留左上高光和右下暗部，没有光晕、
  圆环或中心刻度；开火判定半径与球体一致（flick 模式仅保留极细的剩余时间弧）。
- **目标一定够得到**：相机 yaw/pitch 的可转范围已按目标安全区反算并放宽，每个刷新点都能被准星
  转到画面中心，不会出现“视角已经拉满、靶还在屏幕外”的情况。

> 默认静音。页面打开、进入训练、命中目标都不会自动出声；需要音效时按 `M` 或点右上角喇叭，
> 再在设置 → 音效里调音量。这样不会在后台或打别的游戏时突然吓你一跳。

## 开始玩

1. 双击 `aimlab.html`。
2. 在大厅选择模式，或按 `Enter` 快速开始上次模式。
3. 相对瞄准模式下，开始训练会锁定鼠标、进入第一人称视角：移动鼠标转动视角，准星固定在画面
   中心，**左键射击**，`Esc` 暂停并释放鼠标。想要普通光标点选，可在设置 → 操作里换「绝对瞄准」。
4. HDR 高光开关在 **设置 → 操作**：检测到 HDR 显示时可手动开关；检测不到时开关置灰，游戏
   按普通渲染运行，不加滤镜也不显示 HDR 标记。
4. 一局结束后会显示评级、命中率、平均 TTK、最高连击、每秒得分曲线和本地最佳。
5. 想要整活：设置 → **整活**，里面有 64 条音效、18 段飞行绿幕梗、22 种全屏特效、44 个表情包，可逐项开关和预览。

### 快捷键

| 按键 | 作用 |
|---|---|
| `1`–`6` | 大厅选择模式 |
| `Enter` | 大厅快速开始 / 结算再来一局 |
| `S` | 打开设置 |
| `M` | 静音 / 开启音效 |
| `F` | 全屏 |
| `Esc` | 游戏中暂停 / 释放鼠标；暂停时继续；结算时回大厅 |
| `R` | 结算页再来一局 |

## 六种训练模式

| 模式 | 时长 | 机制 |
|---|---|---|
| 网格速射 GRIDSHOT | 60s | 九宫格保持三个静态靶，命中即补位；练急停与点击效率 |
| 蜘蛛速射 SPIDERSHOT | 60s | 四靶环形随机刷新，距中心越远加成越高 |
| 动态速射 MOTION SHOT | 60s | 三个移动靶碰撞反弹，练预判 |
| 甩枪训练 FLICKSHOT | 45s | 单靶远距闪现，1.7s 存活时间，超时算失误 |
| 跟枪训练 TRACKING | 30s | 不需要点击；准星持续在移动靶内累积分数和连击 |
| 微操精准 PRECISION | 45s | 2 个超小静态靶，慢即是快 |

计分规则：命中中心有精度加成，连击倍率最高 ×2；打空或目标超时会清空连击。评级 S/A/B/C/D
按各模式阈值计算；每模式最佳成绩、最近训练都保存到 localStorage。

## 节目效果（Meme FX）

- **64 条梗音效**：命中池 41 条、打空池 23 条，含实时合成的空气喇叭、Vine Boom、唱片刮擦、悲情长号等。
- **18 段飞行绿幕梗**：随机位置、随机大小弹出，自动抠绿并带画面边框与出处小标。
- **22 种全屏特效**：5 段仓库自带全屏视频 + 5 段额外免费视频 + 12 种程序化动画（烟花、火焰、爆炸、冲击波、流星、彩带、故障、闪电、爱心、表情包雨、大字暴击等）。
- **44 个 Twemoji 表情**：命中/打空时从准星位置弹出，也有全屏表情包雨。
- **三档强度**：克制 / 标准 / 全家桶。可单独关闭音效、飞行梗、全屏特效、表情包；支持逐条试听与预览。
- **默认全局限音**：所有音频共用全局静音和音量；视频本身是静音的。
- **可恢复默认**：整活面板底部有恢复按钮。

音效与视频都在本地单文件里，运行时不请求任何第三方资源。

## 数据与隐私

- 成绩仅保存在当前浏览器 `localStorage`：
  - `aimlab.web.settings.v1`（设置）
  - `aimlab.web.records.v1`（各模式最佳 + 最近 40 局）
  - `aimlab.web.meme.v1`（节目效果设置）
- 不上传、无账号、无在线排行榜。
- 清除浏览器站点数据会一并清空；也可以在 设置 → 数据 中只清训练记录或恢复默认设置。
- 小提示：`file://` 打开时，不同浏览器对本地文件存储的策略可能不同；如果发现刷新后记录消失，请换 Chrome / Edge 或把文件固定在同一个路径。训练结束前尽量不要清浏览器缓存。

## 文件与重建

交付目录：

```
outputs/
  aimlab.html          单文件成品（含全部音效、视频、Emoji）
  README.md            本说明
  ASSET-CREDITS.md     素材来源与许可证
```

如果想修改源码：工程源文件在 `src/`（`index.html` / `styles.css` / `styles-meme.css` / `js/*` / `assets/*`），
在项目根运行：

```powershell
node dpsk/build.mjs
```

即可重新生成单文件。`node dpsk/build.mjs --no-assets` 可生成不含素材的轻量调试版（仅供本地 HTTP 调试）。

## 已知限制

- 指针锁定需要用户在点击中触发；部分内嵌浏览器/隐私设置可能禁止，此时会自动降级为绝对瞄准。
- 没有服务器与在线账号，成绩不跨设备同步。
- 低端设备上同时开启「全家桶」+ 高 DPI 可能掉帧，可在设置中关闭画面特效或降低整活强度。
- 本项目是非官方粉丝作品，与 Aim Lab 无关联；素材授权见 [ASSET-CREDITS.md](./ASSET-CREDITS.md)。
