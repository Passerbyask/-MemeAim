## MemeAim 3D v1.2.0：手柄测试与体感瞄准

- 新增「手柄测试」：左右摇杆原始位置、死区输出、外圈轨迹、两秒中心漂移检测与建议死区。
- 扳机深度、全按键及额外轴实时监视，可选择多个连接设备，支持一次短震动测试。
- DualSense / DualSense Edge WebHID 陀螺仪接入：静止校准、实时角速度、灵敏度、按住 LT / L2 或始终启用、水平轴选择及反转。
- Windows 版可连接本机 Cemuhook DSU 运动服务，供已有驱动能输出真实运动数据的其他手柄使用。
- 体感与右摇杆同时瞄准；未校准、数据过期或窗口失焦时停止体感移动，保留原有训练、震动及全部梗特效。

### 下载与使用

- **Portable.zip**：完整解压，运行文件夹中的 `MemeAim 3D.exe`。
- **Setup.exe**：安装向导。
- **SHA256SUMS.txt**：下载校验值。

Windows 10 / 11 x64，可离线运行，不需要 Python 或 Node.js。更新后打开「手柄测试」，直连 DualSense、确认数据、放稳校准，再开启体感并从首页开始手柄训练。

Xbox 标准输入没有陀螺仪数据。飞智等国产手柄的体感取决于具体型号、模式和驱动；DSU 接口不包含品牌专有驱动，也不能给无传感器的设备增加体感。WebHID 使用名义比例加零偏校准，未实现工厂增益校准。当前未做商业代码签名。

验证包含规则/协议测试、本机 UDP 收发和实际打包程序中的模拟手柄、HID 校准、死区与震动检查；尚未逐款实体手柄实机验证。
