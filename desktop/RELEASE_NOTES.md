## MemeAim 3D-DeepSeek V41 v1.0.0

`dpsk` 分支的独立正式版本，基于用户提供的 DeepSeek V41 网页项目打包。

- 六种模式：网格速射、蜘蛛速射、动态速射、甩枪训练、跟枪训练、微操精准。
- 第一人称训练舱与代码生成枪模，相对/绝对瞄准，鼠标和触屏操作。
- 内嵌梗音效、绿幕视频、表情和全屏特效；默认静音，可在游戏内开启。
- 设置、最佳成绩与训练记录仅保存在本机，独立于 main 版存档。
- 本正式版与 main 并行，不作为预发布，也不替换 main 的 Latest 下载入口。

### 下载

- **Setup.exe**：安装版。
- **Portable.zip**：完整解压后运行 `MemeAim 3D-DeepSeek V41.exe`。
- **SHA256SUMS.txt**：校验值。

Windows 10 / 11 x64，可离线运行，不需要 Python 或 Node.js。此版沿用导入项目功能，不包含 main 的手柄测试和陀螺仪。HDR 增强仍取决于系统和显示设备，不保证实际峰值亮度。当前安装包未做商业代码签名。

素材来源与许可保留在 `dpsk/ASSET-CREDITS.md` 和游戏内。自动验证涵盖实际打包程序、六模式、暂停/结算/存档、默认静音和内嵌音视频解码。
