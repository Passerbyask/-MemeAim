## MemeAim 3D v1.1.0：手柄支持

- 新增标准手柄输入：右摇杆瞄准，RT / R2 按住连续射击，A / × 单发。
- LT / L2 降速精瞄；A / × 开始和确认，B / ○ 返回，Start / Options 暂停或继续。
- 方向键左右或 LB / RB 选择训练模式，方向键上下或左摇杆选择暂停菜单操作。
- 独立手柄灵敏度、摇杆死区及连接提示；断线自动暂停，重连和窗口失焦后需要释放按键再确认继续。
- 开枪轻震、命中较强震动，可独立关闭；支持双马达震动接口时生效。
- 手柄成绩与鼠标成绩分类保存，保留此前所有梗与全屏特效。

### 下载与运行

- **Portable.zip**：完整解压，双击文件夹中的 `MemeAim 3D.exe`。
- **Setup.exe**：安装到电脑并创建快捷方式。
- **SHA256SUMS.txt**：下载校验值。

Windows 10 / 11 x64，可离线运行，无需安装 Python 或 Node.js。首次连接手柄先按一下按键唤醒；推荐使用系统识别为标准布局的手柄，未识别布局可切换 XInput 模式。

当前未做商业代码签名，Windows 可能显示未知发布者。自动测试使用模拟标准手柄，未代替各品牌实体手柄的实机兼容性验证。
